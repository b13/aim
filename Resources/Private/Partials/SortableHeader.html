Deliberately uses the pre-v14.2 Bootstrap `data-bs-toggle="dropdown"` mechanism, not core's newer native-popover pattern (popovertarget/popover attributes), which only landed in TYPO3 v14.2 and doesn't exist in v12.4/v13.4 at all. Bootstrap's own dropdown JS remains bundled in v14 for backwards compatibility, so this works unchanged across all three.
